# lib

Funções que buscam e organizam os dados.

| Arquivo | O que faz |
|---|---|
| `tse.ts` | Chama a API de resultados do TSE e converte a resposta para o nosso formato |
| `municipios.ts` | Lista os municípios da Bahia (TSE + regiões do IBGE) e faz a busca por nome |
| `formatar.ts` | Mostra números no padrão brasileiro (4.019.830 e 49,45%) |
